# multitools-integritetspolicy

**Apex Multi Tools Integritetspolicy På Svenska** 


Integritetspolicy & Användarvillkor
​Senast uppdaterad: [4 november 2026]

​Detta dokument beskriver hur [Apex Multi Tools Group] (hädanefter "vi", "oss" eller "vår") samlar in, använder och skyddar dina personuppgifter samt de villkor som gäller när du beställer anpassade applikationer ("custom appar") från oss.

​1. Personuppgifter vi samlar in och varför
​För att kunna utveckla och leverera din anpassade app samlar vi in följande information när du kontaktar eller anlitar oss:
​Kontaktinformation: Namn, e-postadress, telefonnummer och ev. användarnamn på kommunikationsplattformar (t.ex. Discord, Telegram, Matrix).
​Projekt- och kravspecifikationer: Information, grafik, filer eller data som du tillhandahåller för att vi ska kunna bygga appen enligt dina önskemål.
​Betalningsinformation: Uppgifter som krävs för att bekräfta transaktioner och genomföra fakturering/betalning.
​Laglig grund: Behandlingen är nödvändig för att vi ska kunna fullgöra vårt avtal med dig (leverera den beställda appen).

​2. Hur vi använder din information
​Vi använder dina uppgifter uteslutande för att:
​Utveckla, testa och leverera den app du har beställt.
​Kommunicera med dig under utvecklingsprocessen och ge support vid leverans.
​Hantera betalningar och administrativ bokföring.
​Vi säljer, hyr inte ut och delar aldrig dina personuppgifter eller din projektdata med tredje part för marknadsföringsändamål.

​3. Datalagring och säkerhet
​Vi sparar dina personuppgifter och projektfiler endast så länge det är nödvändigt för att fullfölja leveransen, erbjuda avtalad support eller uppfylla lagstadgade krav (t.ex. bokföringslagstiftning).
​Vi vidtar lämpliga tekniska och organisatoriska säkerhetsåtgärder för att skydda din information mot obehörig åtkomst eller förlust.

​4. Ansvarsbegränsning och Garantier
​4.1 Funktionsgaranti vid Leverans
​Vi garanterar endast att den levererade applikationen fungerar i enlighet med de krav och specifikationer som uttryckligen har avtalats mellan dig och oss vid leveranstillfället ("Godkänt leveransskick").

​4.2 Friskrivning från övriga garantier
​Inga drifts- eller vinstgarantier: Vi lämnar inga garantier gällande appens framtida kommersiella framgång, användarantal, intäkter eller oavbrutna tillgänglighet.

​Tredjepartstjänster och uppdateringar: Vi ansvarar inte för funktionsdugligheten eller framtida ändringar i tredjepartstjänster, API:er, operativsystem (t.ex. framtida Android-/iOS-uppdateringar) eller plattformar som appen är beroende av, utöver vad som uttryckligen ingår i ett eventuellt separat underhållsavtal.
​Ingen skadeståndsskyldighet: Vi ansvarar inte för några indirekta skador, förlorad data, utebliven vinst eller andra följdskador som kan uppstå till följd av användningen av appen.

​5. Dina rättigheter (GDPR)
​Som registrerad har du rätt att:
​Begära ett utdrag över vilka personuppgifter vi har sparade om dig.
​Begära att felaktiga uppgifter rättas.
​Begära att vi raderar dina personuppgifter (med reservation för uppgifter vi enligt lag är skyldiga att spara).
​För att utöva dina rättigheter, kontakta oss på e-postadressen nedan.
